# 중학교 정보 통합 자료실 (공개본)

중학교 정보 교과 5개 영역(컴퓨팅 시스템·데이터·알고리즘과 프로그래밍·인공지능·디지털 문화)의
**52개 개념**을 교사 수업 준비용으로 정리한 자립형 웹사이트입니다. 빌드 도구 없이 순수 HTML/CSS/JS로 동작합니다.

## 바로 보기
`index.html`을 브라우저로 열면 됩니다. (별도 설치 불필요)

## 담긴 내용 (직접 제작/재서술)
- 개념별 **통합정의·쉬운설명·비유·수업용 설명·생활 예시**
- **교사용 심화**(자세히 알아보기) 접이식 블록
- 개념 **도식(SVG) 20종** — 하드웨어 구성, 소리 3단계, 2진수, AI/ML/DL, CCL 등
- 개념별 **실습 아이디어·발문·모범답안 방향**, 지도상 유의점
- 45분 수업 흐름 자동 구성, 단원 복습·형성평가 시트, 전역 검색, 준비 체크·메모(localStorage)

## 공개본에서 조정한 것 (저작권)
- **교과서 출판사별 정의 비교(쪽수 포함)** 와 **공통점·차이 비교** 는 저작물 편집에 해당해 공개본에서 제외했습니다.
- 실습은 그대로 담되, 교과서 수록 활동은 **출판사·쪽 등 출처 없이 '수업 활동 아이디어'로만** 표기했습니다(활동 아이디어 146 + 교사 추천 실습 52).
- 위 원본(정의·쪽·출처)은 개인 로컬 전체본(`자료실`)에만 있습니다.

## 안내
- 개인 교육용으로 만든 자료이며, 정의·예시는 교과서를 **요약·재서술**한 것입니다(원문 복제 아님).
- 페이지 표기가 일부 ±1~2쪽 다를 수 있고, 이오북스(스캔본)는 원문 확보가 어려워 일부 개념 근거가 얇습니다.
- 오류를 발견하면 이슈로 알려 주세요.
